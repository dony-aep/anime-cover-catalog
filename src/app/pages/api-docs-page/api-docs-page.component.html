Anime Cover Catalog API

A public, read-only REST API to browse the curated anime cover catalog: titles, metadata and cover images. No API key required.

Public & free · No authentication · JSON responses · Edge-cached

Please build something new. Don't use this API to clone this catalog into the same kind of product. It is intentionally open for other uses: web and mobile apps, integrations, experiments, or anywhere an anime catalog is genuinely useful.

GET /animes

Returns a paginated, filterable and sortable list of animes.

Different parameters combine with AND; commas inside one parameter combine with OR. ?genre=Romance,Comedy&theme=School means (Romance OR Comedy) AND School.

Query parameters

qstring
Search across title, English and Japanese titles. Case- and accent-insensitive (roze finds Rozé). Max 100 characters.
genrestring
One genre or a comma-separated list (OR), e.g. Romance,Comedy. Case-insensitive; unknown values return 400.
themestring
One theme or a comma-separated list (OR), e.g. School. Case-insensitive; unknown values return 400.
demographicstring
One demographic or a comma-separated list (OR), e.g. Shounen. Case-insensitive; unknown values return 400.
typestring
One type or a comma-separated list (OR), e.g. TV,Movie. Case-insensitive; unknown values return 400.
yearinteger
Release year, e.g. 2024.
fieldsstringDefault: all fields
Comma-separated subset of fields to return, e.g. slug,title,genres. Unknown names return 400.
sorttitle | yearDefault: title
Field to sort by.
orderasc | descDefault: asc
Sort direction.
pageinteger ≥ 1Default: 1
Page number.
limitinteger 1–100Default: 24
Items per page (max 100).

links.next and links.prev are ready-to-follow absolute URLs that keep your active filters (null on the first/last page).

GET /animes/random

Returns one random anime, ideal for "surprise me" or daily-pick features. Honors the list filters (q, genre, theme, demographic, type, year) and fields; responds 404 when no anime matches.

Never cached (Cache-Control: no-store), so every request gets a fresh pick.

GET /filters

Returns the distinct genres, themes, demographics, types and years available in the catalog, useful to build filter UIs. Filter values sent to /animes must come from this list.

Limits & fair use

Pagination
limit is capped at 100 items per page (default 24). Use page to iterate.
Caching
Responses are cached on Vercel's edge network (server-side, not your browser) via Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800: fresh for 24 h, then served stale for up to 7 days while it revalidates. The cache is invalidated on each deploy, so most requests never reach the function. /animes/random is the exception: never cached.
Conditional requests
Every 200 response carries an ETag that changes only on deploy. Re-fetch with If-None-Match and you'll get 304 Not Modified with an empty body when nothing changed.
Rate limit
Traffic is rate-limited per IP (100 requests per minute). Above that you may receive 429 responses; cache on your side and you'll never notice it.
CORS
Open to any origin, safe to call from the browser.

Errors

All errors use standard HTTP status codes and share the same JSON shape, so you can handle them uniformly.

200
Success.
304
Not modified: your If-None-Match ETag is still current; the body is empty.
400
Invalid query parameter, e.g. limit above 100, an unknown fields name, or a genre/theme/demographic/type value that doesn't exist in the catalog (the message points you at /filters).
404
No anime matches the requested slug, or no anime satisfies the filters passed to /animes/random.
429
Rate limit exceeded (100 requests per minute per IP). Back off and retry.
